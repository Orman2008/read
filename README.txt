COMIC VOICE READER V3

Что изменено:
1. OCR использует только русский язык.
2. В распознавание разрешены только русские буквы А-Я, а-я, Ё, ё.
3. После OCR дополнительно удаляются ВСЕ цифры и символы.
4. Слова фильтруются по светлому/белому фону вокруг них — это отсекает большую часть текста вне речевых облачков.
5. Режим "Начать комикс": читает страницу и автоматически переходит к следующей, пока страницы не закончатся.

Запуск:
1. Распаковать ZIP.
2. Запустить start.bat.
3. Откроется http://localhost:8000
4. Загрузить страницы в правильном порядке.
5. Нажать "Начать комикс".

Важно:
- Для OCR нужен интернет при первом запуске, так как Tesseract.js и русский языковой пакет загружаются через CDN.
- На iPhone/Android используй Safari/Chrome и обычный HTTPS-хостинг. Предпросмотр файла внутри ChatGPT/Telegram может блокировать голос или выбор файлов.
