COMIC VOICE READER

КАК ЗАПУСТИТЬ НА WINDOWS

1. Распакуй ZIP.
2. Дважды нажми start.bat.
3. Откроется Chrome/Edge на:
   http://localhost:8000
4. Нажми «Выбрать страницы».
5. Выбери несколько JPG/PNG страниц комикса.
6. Один раз нажми «Включить голос».
7. OCR распознает текст и начнет чтение.
8. После окончания страница автоматически переключится.

ВАЖНО
- Не открывай index.html внутри предпросмотра ChatGPT, Telegram или приложения «Файлы».
- OCR загружает Tesseract.js через интернет.
- Голоса берутся из Windows/macOS/iOS/Android. Поэтому конкретное имя голоса зависит от устройства.
- На телефоне сайт лучше размещать на обычном HTTPS-хостинге.

ДЛЯ КОМИКСОВ
- Чем четче текст и крупнее облачки, тем точнее OCR.
- Встроена обработка изображения: увеличение + grayscale + контраст.
- После OCR текст можно исправить вручную перед озвучкой.
